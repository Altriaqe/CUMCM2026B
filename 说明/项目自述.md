# CUMCM 2026 B 题 —— 无线电干扰源快速自动定位与清除（骨架）

## 文件结构

| 文件 | 作用 |
|---|---|
| `client.py` | 模拟器 HTTP 客户端（4 条指令 + 幂等重试 + 日志） |
| `geometry.py` | 问题 1/2 计算几何 + 多示向度最小二乘定位 |
| `strategy.py` | 问题 3/4 覆盖扫描 + 定位 + 清除策略 |
| `robot.py` | 问题 3 主程序（全向干扰源） |
| `mock_simulator.py` | 本地 mock 模拟器，赛前联调，不依赖官方 |

## 快速上手（本地 mock 联调）

```bash
# 终端 1：启动 mock（会打印真实位置供复盘）
python mock_simulator.py --seed 1 --sources 13

# 终端 2：跑机器狗
python robot.py
```

观察打印的「清除 N 个 / 平均定位清除时间」，和 mock 打印的真实位置对照复盘。

## 核心思路（两阶段）

1. **覆盖扫描**：圆心 + 半径 1400 圆上 6 点（共 7 个检测点），每个点按频道 1..20
   检测，覆盖整个 1800m 圆域（按最坏接收半径 1000m 设计，`verify_coverage` 可验证）。
   发现所有干扰源并采集多条示向度。
2. **定位 + 清除**：每个频道用最小二乘定位，再按近邻顺序「测向—逼近—清除」。

## 关键可调参数（对着模拟器磨）

- `coverage_points` 的点数与半径：更多点更稳但更慢。
- `detection_sweep` 的 `min_sightings`：每频道集满几条示向度就跳过（省时）。
- `homing_clear` 的 `step0`：定位误差大就调大，误差小就调小。
- `clear_order` 近邻贪心：可换 2-opt / 真实 TSP。

## 优化方向（时间大头）

1. **移动是大头**（5 m/s）。近邻贪心换 TSP 求解器，清除巡回能省不少。
2. **频道切换**（1s/次）：集满示向度就跳过该频道（已内置），可再调 `min_sightings`。
3. **检测与清除交织**（贪心）：避免「扫完再回来」的重复路程。

## 问题 4（定向干扰源）注意

- 定向源只有检测点落入其 180° 覆盖锥内才有信号，覆盖扫描可能漏掉。
- 需要更密的扫描点（覆盖锥），或对 no_signal 但疑似存在的频道做二次多角度逼近。
- 清除不受锥限制（光学），关键是「找到并进入锥内」。
