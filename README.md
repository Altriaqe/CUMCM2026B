# CUMCM 2026 B 题：无线电干扰源定位与清除

本仓库包含数学建模论文、算法源码和可复现实验结果汇总。

## 目录

- `程序/核心程序/`：模拟器客户端、几何计算、搜索策略和本地 mock。
- `程序/分析脚本/`：用于分析和绘图的脚本。
- `结果/`：脱敏后的汇总结果；原始运行轨迹不纳入仓库。
- `论文/`：论文源码、PDF 和正文引用的图片。
- `说明/项目自述.md`：核心程序的快速上手说明。

## 快速开始

```bash
cd 程序/核心程序
python mock_simulator.py --seed 1 --sources 13
```

另开终端运行：

```bash
cd 程序/核心程序
python robot.py --id test
```

连接真实模拟器时，请通过命令行或环境变量提供队伍标识，不要把真实标识写入源码：

```bash
python robot.py --id "<YOUR_TEAM_ID>"
```

程序默认只连接本机模拟器（`127.0.0.1:2026`）。依赖为 Python 3.11，以及按需安装的 `numpy`、`matplotlib` 和 `scipy`。
